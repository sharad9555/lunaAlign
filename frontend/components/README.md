# Component map

The offline dashboard currently ships as a dependency-free single page for reliable SIH demonstrations. Its logical components are ImageUpload/ProcessingConfig, MetricsPanel, RegistrationViewer, MatchViewer, ConfidenceMap, ErrorMap, SpatialCoverage, BenchmarkTable and ExperimentHistory. A Vite/React package manifest is included at `frontend/package.json` for a component migration without changing the API.
