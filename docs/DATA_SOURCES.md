# Data sources policy

No random lunar imagery is represented as Chandrayaan-2 data. Place authorised sample files in `data/sample/` and record source, sensor, acquisition identifier, access/licence, known pixel scale, sun geometry, CRS, and preprocessing in an accompanying JSON file.

Potential sources to evaluate manually: ISSDC Chandrayaan-2 archives (follow their access terms), NASA LRO NAC archives, and JAXA SELENE archives. If access requires registration, complete it manually; this project does not bypass access controls. The Phase-1 tests generate synthetic crater-like images only to verify mechanics, not scientific performance.
